# Incident Report Logger

A Python command-line tool for logging and tracking workplace safety incidents.

## Features
- Log new incidents with date, time, location, type, and severity
- View all past incident reports
- Summary breakdown of incidents by severity level
- Saves all data to a CSV file for recordkeeping

## How to Run
python incident_logger.py

## Built With
- Python 3
- csv, os, datetime (standard libraries)
